## 📚 基础知识概述

本部分包含了Go后端开发所需的基础知识，包括Go语言核心、数据结构和算法等内容。

## 📖 知识体系

### Go语言核心
- Go语言基础语法
- Go语言并发模型
- Go语言内存管理
- Go语言标准库
- Go语言高级特性

### 数据结构
- 数组与切片
- 链表
- 栈与队列
- 树与图
- 哈希表
- 堆与优先队列

### 算法
- 排序算法
- 查找算法
- 字符串算法
- 图算法
- 动态规划
- 贪心算法

## 💡 学习建议

1. **打好基础**：基础知识是后续学习的基石，一定要扎实掌握
2. **多做练习**：通过大量的编程练习巩固所学知识
3. **深入理解**：不仅要知道怎么做，还要知道为什么这么做
4. **联系实际**：思考如何将这些基础知识应用到实际项目中
