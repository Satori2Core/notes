# 开发随笔

> 记录开发过程中的学习、思考与实践

## 🌟 欢迎来到我的学习记录

你好，我是一名Go后端开发的学习者。2024年通过C++校招进入金山办公后，开始接触Go语言进行后端开发。一年半下来，感觉自己只能写简单的业务代码，在代码设计、可维护性、可扩展性以及工程架构方面还有很多不足。

这个网站是我重新开始的学习记录，主要用于：
- 记录学习过程中的知识点和思考
- 制定并跟踪学习规划
- 总结项目开发中的经验教训
- 分享学习资源和心得体会

我不是什么大神高手，只是一个想不断提升自己的学习者。希望通过系统的学习，能够达到行业内3年工作经验的技术水平，成为一名合格的、能干活儿的Go后端工程师。

## 📚 网站结构

### 基础知识
- **Go语言核心**：Go语言的基础语法、并发模型、内存管理等核心知识点
- **数据结构**：常用数据结构的原理和实现
- **算法**：经典算法的分析和Go语言实现

### 后端技术
- **数据库**：MySQL、PostgreSQL等关系型数据库和Redis、MongoDB等NoSQL数据库
- **缓存**：Redis等缓存技术的应用和最佳实践
- **消息队列**：Kafka、RabbitMQ等消息队列的使用和架构设计
- **微服务**：微服务架构的设计和实践
- **API设计**：RESTful API和GraphQL的设计原则

### 工程实践
- **代码设计**：代码重构、设计模式、SOLID原则等
- **测试**：单元测试、集成测试、端到端测试等
- **CI/CD**：持续集成和持续部署的实践
- **架构设计**：系统架构设计的原则和案例分析

### 项目实战
