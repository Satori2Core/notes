## 2. 可见性控制方法

### 2.1 如何让笔记公开可见
1. 将笔记放在导航栏配置中已存在的目录下
2. 确保目录结构符合config.js中的侧边栏配置
3. 运行构建命令后，笔记会自动出现在对应导航菜单中

### 2.2 如何让笔记仅自己可见
1. 将笔记放在`docs/learning-plan/`或`docs/notes/`目录下
2. 这些目录未在导航栏和侧边栏中配置，网站访问者无法通过导航找到
3. 你可以通过直接URL访问：
   - 学习计划：`http://your-site/notes/learning-plan/`
   - 临时笔记：`http://your-site/notes/notes/`

## 3. 笔记编写规范

### 3.1 文件命名
- 使用中文或英文命名，保持一致性
- 避免使用特殊字符，使用短横线分隔单词
- 示例：`docs/foundations/go-core/变量与常量.md`

### 3.2 Markdown格式
- 使用标准Markdown语法
- 添加合适的标题层级
- 使用代码块展示代码示例
- 添加适当的注释和说明

### 3.3 图片管理
- 公开笔记图片：放在对应目录下或`docs/.vuepress/public/`目录
- 私人笔记图片：建议放在`docs/learning-plan/images/`或`docs/notes/images/`
- 图片引用格式：`![图片描述](/路径/图片名称.png)`

## 4. 网站操作命令

### 4.1 本地预览
```bash
npm run dev
```

### 4.2 构建网站
```bash

```
构建输出：`docs/.vuepress/dist/`

```bash

```

## 6. 学习计划管理

### 6.1 年度计划
- 文件位置：`docs/learning-plan/yearly/README.md`
- 记录全年学习目标和里程碑

### 6.2 月度计划
- 文件位置：`docs/learning-plan/monthly/`
- 每个月创建一个文件，如：`docs/learning-plan/monthly/2025-12.md`
- 记录当月学习任务和完成情况

### 6.3 周度计划
- 文件位置：`docs/learning-plan/weekly/`
- 每周创建一个文件，如：`docs/learning-plan/weekly/2025-W51.md`
- 记录每周学习任务和完成情况

## 7. 常见问题

### 7.1 笔记不显示在导航栏
- 检查笔记是否放在正确的目录下
- 检查config.js中的导航和侧边栏配置
- 重新构建网站

### 7.2 本地预览看不到新笔记
- 确保使用`npm run dev`启动开发服务器
- 检查文件路径是否正确
- 尝试清除浏览器缓存

### 7.3 构建失败
- 检查Markdown语法是否正确
- 检查图片引用路径是否正确
- 查看错误日志，定位问题所在
