# Go语言笔记编写操作文档

# 1. 笔记编写位置

# 1.1 公开笔记（网站导航可见）

  • Go语言核心：docs/foundations/go-core/

    • 适合编写Go语言核心知识点、语法、特性等笔记
    • 在网站导航栏的「基础知识」→「Go语言核心」中可见

  • 后端技术相关：

    • 数据库：docs/backend-tech/database/
    • 缓存：docs/backend-tech/cache/
    • 消息队列：docs/backend-tech/message-queue/
    • 微服务：docs/backend-tech/micro-services/
    • API设计：docs/backend-tech/api-design/

  • 工程实践相关：

    • 代码设计：docs/engineering/code-design/
    • 测试：docs/engineering/testing/
    • CI/CD：docs/engineering/ci-cd/
    • 架构设计：docs/engineering/architecture/

# 1.2 私人笔记（仅自己可见）

  • 学习计划：docs/learning-plan/

    • 年度计划：docs/learning-plan/yearly/
    • 月度计划：docs/learning-plan/monthly/
    • 周度计划：docs/learning-plan/weekly/
    • 此目录在网站导航栏中不可见，仅通过直接URL访问

  • 临时笔记：docs/notes/

    • 适合存放临时笔记、草稿、未整理的内容
    • 此目录在网站导航栏中不可见，仅通过直接URL访问

# 2. 可见性控制方法

# 2.1 如何让笔记公开可见

  1. 将笔记放在导航栏配置中已存在的目录下
  2. 确保目录结构符合config.js中的侧边栏配置
  3. 运行构建命令后，笔记会自动出现在对应导航菜单中

# 2.2 如何让笔记仅自己可见

  1. 将笔记放在docs/learning-plan/或docs/notes/目录下
  2. 这些目录未在导航栏和侧边栏中配置，网站访问者无法通过导航找到
  3. 你可以通过直接URL访问：
    • 学习计划：http://your-site/notes/learning-plan/
    • 临时笔记：http://your-site/notes/notes/

# 3. 笔记编写规范

# 3.1 文件命名

  • 使用中文或英文命名，保持一致性
  • 避免使用特殊字符，使用短横线分隔单词
  • 示例：docs/foundations/go-core/变量与常量.md

# 3.2 Markdown格式

  • 使用标准Markdown语法
  • 添加合适的标题层级
  • 使用代码块展示代码示例
  • 添加适当的注释和说明

# 3.3 图片管理

  • 公开笔记图片：放在对应目录下或docs/.vuepress/public/目录
  • 私人笔记图片：建议放在docs/learning-plan/images/或docs/notes/images/
  • 图片引用格式：![图片描述](/路径/图片名称.png)

# 4. 网站操作命令

# 4.1 本地预览

npm run dev

访问：http://localhost:8080/notes/

# 4.2 构建网站

npm run build

构建输出：docs/.vuepress/dist/

# 4.3 调试构建

npx vuepress build docs --debug

# 5. Git操作流程

# 5.1 提交笔记

git add docs/路径/你的笔记.md
git commit -m "添加Go语言笔记：XXXXX"
git push origin main

# 5.2 查看提交历史

git log --oneline

# 6. 学习计划管理

# 6.1 年度计划

  • 文件位置：docs/learning-plan/yearly/README.md
  • 记录全年学习目标和里程碑

# 6.2 月度计划

  • 文件位置：docs/learning-plan/monthly/
  • 每个月创建一个文件，如：docs/learning-plan/monthly/2025-12.md
  • 记录当月学习任务和完成情况

# 6.3 周度计划

  • 文件位置：docs/learning-plan/weekly/
  • 每周创建一个文件，如：docs/learning-plan/weekly/2025-W51.md
  • 记录每周学习任务和完成情况

# 7. 常见问题

# 7.1 笔记不显示在导航栏

  • 检查笔记是否放在正确的目录下
  • 检查config.js中的导航和侧边栏配置
  • 重新构建网站

# 7.2 本地预览看不到新笔记

  • 确保使用npm run dev启动开发服务器
  • 检查文件路径是否正确
  • 尝试清除浏览器缓存

# 7.3 构建失败

  • 检查Markdown语法是否正确
  • 检查图片引用路径是否正确
  • 查看错误日志，定位问题所在

注意：本操作文档仅自己可见，通过URL：http://your-site/notes/learning-plan/操作文档/ 访问。
